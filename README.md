# Local Lo-Fi Radio for Omarchy

Минималистичный виджет для верхней панели **Omarchy** (Quickshell), генерирующий бесконечный Lo-Fi Hip Hop локально в реальном времени без интернета и аудиофайлов.

## Особенности
* **100% локальная генерация на Python (`numpy` + `sounddevice`):** теплые джазовые аккорды электропианино, саб-бас, ударные со свингом, импровизирующая мелодия и виниловый треск.
* **Три атмосферных режима:**
  * `♫` **Chill** — расслабленный джазовый бит (76 BPM)
  * `☂` **Rainy** — меланхоличные минорные аккорды с шумом дождя (68 BPM)
  * `☕` **Study** — собранный ритм для работы и учебы (84 BPM)
* **Минимальная нагрузка:** 0% CPU и 0 МБ RAM в режиме паузы.

## Управление
* **Левый клик** — включить / поставить на паузу.
* **Правый клик** — переключить настроение (`Chill` → `Rainy` → `Study`).
* **Колесико мыши** — регулировка громкости генератора (0%–150%).

## Зависимости
```bash
sudo pacman -S --needed python-numpy python-sounddevice
```

## Установка
```bash
omarchy plugin add https://github.com/Kjubas/omarchy-lofi-radio --enable
```
